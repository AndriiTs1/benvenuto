# Benvenuto
Приложение для изучения итальянского языка шаг за шагом, уровни A1 → C2.
Начинаем с уровня A1 (с нуля). Интерфейс приложения — на итальянском.
Пока без привязки к какой-либо стране или городу.

## Стек
- Next.js (App Router, папка src/app), TypeScript, Tailwind CSS v4
- Пока НЕТ базы данных, логина и внешних API
- Контент уроков будет храниться в JSON в src/content

## Дизайн
- Цвета (Tailwind-токены): lago #10263A, lago-2 #24425C, sole #F2B33D, verde #1F7A74, fondo #F4F5F0
- Шрифты: Bricolage Grotesque (заголовки, font-display), Figtree (текст, font-sans) через next/font/google
- Mobile-first: контент в колонке max-w-md по центру, кнопки высотой не меньше 44px
- Без эмодзи в интерфейсе, иконки — inline SVG
- Тексты интерфейса на итальянском

## Правила работы
- Делай только то, что указано в задании
- Не устанавливай новые пакеты без разрешения
- Не трогай файлы, которые не относятся к заданию
- В конце работы выведи список созданных и изменённых файлов
- Перед завершением запусти npm run lint и исправь ошибки
