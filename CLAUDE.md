# Benvenuto
Приложение для изучения итальянского языка шаг за шагом, уровни A1 → C2.
Начинаем с уровня A1 (с нуля). Интерфейс приложения — на итальянском.
Пока без привязки к какой-либо стране или городу.

## Стек
- Next.js (App Router, папка src/app), TypeScript, Tailwind CSS v4
- Пока НЕТ базы данных, логина и внешних API
- Контент уроков будет храниться в JSON в src/content

## Дизайн (стиль Apple / iOS)
- Шрифт: системный (-apple-system, SF Pro). Без next/font.
- Цвета только через токены: bg, bg-grouped, card, label, label-2, separator, accent, success, error, warning
- Главные кнопки — "капсула": rounded-full, фон label, текст bg (в тёмной теме автоматически инвертируются: белая кнопка, чёрный текст)
- Синий accent — только для мелких акцентов внутри уроков (выбранный вариант, ссылки в тексте). Не для больших кнопок и заголовков
- Второстепенный текст — label-2 (серый)
- success/error только для правильных/неправильных ответов
- Поддержка тёмной темы через prefers-color-scheme
- Крупные жирные заголовки, тонкие разделители, скругления rounded-2xl/rounded-3xl
- Кнопки и нажимаемые элементы не меньше 44px
- НИКАКИХ иллюстраций, эмодзи, градиентов, игровых элементов. Это учебный инструмент
- Тексты интерфейса на итальянском

## Дизайн-правила Benvenuto
- Интерфейс на итальянском; объяснения на языке студента (ru / uk / en, cookie bv_lang).
- Любой текст на языке объяснений выводится ТОЛЬКО через <Tr> (src/components/Tr.tsx,
  цвет --color-translation: #4B5BA6 светлая / #A5B4FC тёмная, атрибут lang). Разметка внутри
  строки: {{…}} — итальянский фрагмент, **…** — жирный; размер — проп size, цвет не менять.
  Итальянский (названия тем и разделов, примеры, ячейки таблиц, wrong/right) — основной цвет текста.
  Служебные подписи (Argomento N, счётчики) — label-2.
- Цвета разделов: grammar #005CB8, vocab #006A7A, exercises #8944AB, communicate #8F5100
  (тёмная тема: #409CFF, #40C8E0, #C878F5, #FFB340) — текст ≥ 4.5:1 и на своём -soft фоне;
- Цвета флага — только бренд / стартовый экран (бейдж «Italiano · A2», превью ссылки):
  --flag-green #097236 / #34C77B (тёмная), --flag-red #B3121F / #FF6B6B (тёмная).
  Не заменяют success/error. success/error — только для «верно/ошибка».
- Все цвета — токены в src/app/globals.css, без хардкода в компонентах. Тени и затемнение тоже токены:
  --shadow-sm, --shadow-md, --shadow-pop, --shadow-sheet, --scrim (в классах: shadow-(--shadow-sm), bg-(--scrim)).
  Исключение: themeColor в src/app/layout.tsx (метаданные браузера, токены там недоступны).
- Иконки — SVG из src/components/lezione/ui.tsx (IconCheck, IconX…), aria-hidden; символы ✓ ✕ в тексте не использовать.
- Мобильный (< md): всё содержимое курса по центру — заголовки, подписи секций, карточки,
  таблицы, сетки, тексты. Исключения: шапка и нижняя панель вкладок (компонент ContenutoCorso
  в src/components/corso/ContenutoCorso.tsx — использовать в layout каждого уровня; правило в globals.css). Desktop (≥ md): тексты и таблицы по левому
  краю, сетки-карточки по центру.
- Исключение: сетки-карточки для запоминания (participi irregolari и подобные) — содержимое ячеек по центру.
- Списки-подписи к фигурам: колонки по центру, текст в ячейке слева.
- Перед коммитом UI-изменений — npm run test:layout (все тесты из tests/: центр на мобильном и без горизонтального скролла — centrato.spec.ts; рамка фокуса переключателя языка — lingua.spec.ts).
- Кольцо фокуса только с клавиатуры: :focus-visible + общий механизм ModalitaInput (src/components/ModalitaInput.tsx, html[data-input]) гасит рамки после клика/касания. Цвет рамки — accent, 2px (focus-visible:outline-accent). Мобильный приоритет, 375px без горизонтального скролла.
- Не использовать git stash / reset / checkout без спроса.

## Адаптивность (обязательно для каждого экрана)
- Mobile-first: базовые стили для телефона, затем sm (640), md (768), lg (1024)
- Телефон: контент на всю ширину, px-4 (стартовый экран — px-6); учитывать safe-area (env(safe-area-inset-*))
- md и выше: контент в колонке по центру (max-w-md для простых экранов; колонка курса — max-w-188, 47rem), заголовки крупнее
- Высота экрана — только min-h-dvh, никогда h-screen и фиксированные высоты для страниц
- Низкие экраны и горизонтальный телефон: ничего не перекрывается, контент прокручивается
- Никаких фиксированных ширин в px для блоков; position absolute — только для декоративных мелочей и всплывающих меню/подложек (меню языка, затемнение под листом)
- Проверять на ширинах 375, 390, 430, 768, 1024, 1440 и в горизонтальной ориентации
