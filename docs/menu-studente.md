# Меню студента — повторение и подсказки

## Вкладки (порядок слева направо)
| Вкладка | Зачем | Что внутри |
| --- | --- | --- |
| Percorso | Учиться дальше | Уровень и прогресс, карточка «Continua», 10 модулей |
| Ripasso | Закреплять | Da ripassare oggi, I miei errori, Parole, Verbi, Test del modulo |
| Quaderno | Подсмотреть в любой момент | Поиск, Vocabolario, Grammatica, Verbi, Numeri e tempo, Frasi utili |
| Profilo | Настроить | Уровень, язык подсказок, цель в день, напоминание, код класса, статистика |

## Ripasso
- Da ripassare oggi — главная карточка: «12 parole · 3 errori · circa 6 min» + кнопка «Ripassa». Интервалы повторения: 1, 3, 7, 14 дней.
- I miei errori — что написал студент и как правильно. Нажатие → упражнение на эту ошибку. 3 верных ответа подряд → ошибка уходит из списка.
- Parole — карточки изученных слов, фильтр по модулю; режимы: IT → родной, родной → IT, на слух.
- Verbi — тренировка спряжений («noi + capire = ?»).
- Test del modulo — короткая проверка по пройденному модулю.

## Quaderno
- Поиск сверху — по словам, глаголам, правилам, фразам.
- Vocabolario — слова по темам, изученные отмечены.
- Grammatica — одно правило = одна карточка с примерами.
- Verbi — ~53 глагола A1 с таблицей спряжения и примером.
- Numeri e tempo — числа, часы, дни, месяцы.
- Frasi utili — полезные фразы.
- Содержимое — из docs/programma-a1.md.

## Profilo
Уровень; язык подсказок (украинский, русский); цель в день 5/10/15 мин; напоминание; код класса школы; статистика: дни занятий, изученные слова, исправленные ошибки.

## Помощь в уроке — кнопка «Aiuto» (нижняя панель)
| Действие | Что делает |
| --- | --- |
| Suggerimento | Первая буква или намёк |
| Traduzione | Перевод на родной язык |
| Regola | Открывает карточку правила из Quaderno, не выходя из урока |
| Ascolta piano | Фраза медленнее |

## Правила логики
- Ответ с подсказкой засчитывается как верный, но задание возвращается в повторение раньше (интервал не растёт).
- Никаких очков, «жизней», рейтингов. Прогресс = изученные слова и исправленные ошибки.
- Quaderno доступен всегда, даже посреди урока.
