# Benvenuto A2 — стандарт объяснения темы

Чек-лист для каждой темы. Тема не считается готовой, пока не выполнены все пункты.

## 1. Порядок страницы
1. **In breve** — максимум 3 строки: что это и когда нужно.
2. **Come si forma** — формула крупно (части только на итальянском), 2–3 примера «части → фраза → перевод», шаги, в каждом шаге пример.
3. **Главный выбор темы** (например, essere/avere, imperfetto/passato) — сразу после формулы, открыт, с простым тестом в 3–4 шага.
4. Таблицы → Errori frequenti → In sintesi → Approfondisci (детали) → Esercizi.

## 2. Правила текста
- Одна мысль — одна строка. Каждое правило с примером, каждый пример с переводом.
- Итальянский термин вводится один раз с переводом: *ausiliare* = вспомогательный глагол, *participio* = причастие. Дальше одни и те же слова во всех темах.
- Не писать «в настоящем», «по правилу» без уточнения: всегда конкретно (*в настоящем времени: ho, sono…*).
- В примерах шагов не использовать вспомогательные/служебные глаголы как обычные (не *avere → avuto* в шаге образования).
- Примеры из жизни студента в Тичино: работа, курс, семья, Лугано, транспорт.

## 3. Опора на родной язык (ru/uk)
- Использовать сходство: прошедшее в русском/украинском тоже меняется по роду (*пошёл/пошла*) → согласование с *essere*.
- Предупреждать о ловушках: артикль, которого нет в ru/uk; *ho freddo* (не *sono freddo*); *mi piace* (подлежащее — то, что нравится); двойное отрицание *non… mai* как в русском.

## 4. Частотность
- Сначала 15–20 самых частых глаголов/слов; редкие — в Approfondisci.

## 5. Упражнения (от узнавания к производству)
- choice (узнать) → fill (образовать) → фраза целиком (в будущем).
- Каждое правило темы покрыто минимум 2 упражнениями; нет упражнений на то, чего нет в объяснении.
- Ни одного вопроса с двумя верными ответами (проверять Lei/tu, м./ж. род).
- Объяснение «why» — одна фраза, ссылается на правило темы.

## 6. Точность
- Каждое спорное правило сверять с Treccani / Accademia della Crusca / стандартной грамматикой. Если допустимы оба варианта (*è piovuto / ha piovuto*) — так и писать.
- Не публиковать тексты учебника дословно — переписывать своими примерами.
- ru, uk, en — одинаковый смысл и структура.
